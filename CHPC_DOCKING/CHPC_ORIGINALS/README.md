# Original CHPC scripts

Extracted from the user-supplied BRD4_NP_DOCKING_original_scripts.tar.gz (26 November 2026). Original relative paths and file content retained. SHA256SUMS records the source-file checksums; run sha256sum -c SHA256SUMS from this directory.

The archive contains eight original files. Baseline and pH 7.5 grid configurations are byte-identical per domain. The original baseline validator reads dry/wet output filenames; it will need a separate adapted copy for pH 7.5 results. The original baseline PBS does not contain a project directive; the pH 7.5 PBS does. These historical originals are not modified.

The consolidated command archive remains in ../WORKFLOW; figures and notebook remain in ../PROPKA_FIGURES. Earlier extraction/water matching commands and raw data, receptors, ligand files, logs and docking poses are not present in the supplied tarball. This is not a full data backup.
